A powerful **command-line Expense Tracker** that helps you manage personal finances, analyze spending patterns, and visualize expenses with charts. This is **Project 2** in my series of Python exercises, bridging beginner and intermediate concepts.

## 🎯 Purpose

This application moves beyond basic CRUD operations to introduce **data persistence with CSV**, **data analysis**, and **visualization**. It helps users track daily expenses and gain insights into their spending habits.

## ✨ Features

- 💸 **Add Expenses** – Record date, category, amount, and description
- 📋 **View All Expenses** – Display expenses in a clean, tabular format
- 📊 **Monthly Summary** – See total spending per month with category breakdown
- 🥧 **Expense Charts** – Visualize spending by category using pie charts
- 📈 **Spending Trends** – Track expenses over time with line graphs
- 💾 **CSV Storage** – All data saved to `expenses.csv` for easy export to Excel
- 🔍 **Filter by Category** – View expenses for specific spending categories

## 🧠 Concepts Covered

This exercise practices the following Python concepts (beginner to intermediate):

| Concept | Implementation |
|---------|----------------|
| **Dictionaries** | Structuring expense data (date, category, amount, description) |
| **CSV File Handling** | Reading/writing expenses to `expenses.csv` with `csv` module |
| **Data Analysis** | Aggregating totals, grouping by category/month with loops |
| **Matplotlib** | Creating pie charts and line plots for visualization |
| **List Comprehensions** | Filtering and transforming expense data |
| **Error Handling** | `try/except` for invalid inputs and file operations |
| **Date Parsing** | Working with `datetime` for monthly aggregation |
